ZZZSwitch — 绝区零三服切换器

ZZZSwitch 是适用于 Windows PC 的《绝区零》服务器切换工具，支持国服官服、国际服与 B服。 它基于官方 Sophon Manifest 获取服务器差异文件，优先复用本地资源，并为每次切换保留可恢复备份。

一份客户端，管理三种服务器资源

跨服差异、热更新缓存和回滚备份由同一套流程管理，减少重复下载，也避免靠手工覆盖文件碰运气。

01 / MANIFEST

官方差异来源

国服官服与国际服切换读取当前游戏版本的官方 Sophon Manifest，只准备目标服真正需要的文件。

02 / REUSE

优先复用本地文件

已经存在且校验一致的文件不会重复下载；反向切换所需差异也会保留在本地。

03 / RECOVERY

可恢复事务

替换前建立备份，配合文件校验、事务日志和自动恢复，降低意外中断造成混合客户端的风险。

服务器状态一眼可见

完整模式集中显示当前客户端、游戏版本、差异包、热更新缓存和备份入口，也提供适合日常快速切换的精简模式。

从下载到切换，只需四步

首次切换需要联网读取 Manifest；之后可以复用已校验的文件和缓存。切换期间必须保持游戏与 HoYoPlay 完全关闭。

STEP 01

下载并解压

从 GitHub Releases 获取最新版压缩包，解压后运行 ZZZSwitch.exe。

STEP 02

选择游戏目录

使用自动检测，或手动选择包含 ZenlessZoneZero.exe 的目录。

STEP 03

检查并切换

选择目标服务器，确认完整性检查与切换摘要后开始操作。

STEP 04

启动目标服

切换完成后启动游戏，首次进入目标服时按提示完成游戏内资源下载。

切换前，请先关闭游戏和启动器

  • 游戏或 HoYoPlay 运行时不要执行切换。
  • 不要在非对应服务器状态下使用官方启动器的“修复”功能。
  • 目标文件校验、磁盘空间或路径安全检查失败时，ZZZSwitch 会停止操作。
  • 首次进入其他服务器，仍可能需要下载约 3–10 GB 游戏内资源。

常见问题

更完整的安装、差异包、缓存和安全说明保存在 GitHub 仓库的中文 README 中。

ZZZSwitch 会下载整个游戏吗？

不会。程序比较目标服 Manifest 与现有客户端，优先复用已经存在且校验一致的文件，只下载本地缺少的目标差异。

B服需要单独下载组件包吗？

当前支持版本的 B服渠道组件已经包含在正式程序中。ZZZSwitch 会自动校验并准备这些组件。

切服后为什么还会下载游戏内资源？

启动文件差异与游戏内热更新资源是两套内容。ZZZSwitch 会分别保存各资源服的 Blocks 缓存，但第一次进入目标服仍需要完成一次资源下载。

出现问题后可以恢复吗？

每次实际替换前都会创建事务备份。可以在备份历史中恢复，也可以在意外中断后重新启动 ZZZSwitch，让程序依据事务记录继续恢复。
