01

软件功能

自动准备差异文件，管理热更新缓存与切换备份。

⌁

下载差异文件

基于当前游戏版本的官方 Sophon Manifest，获取国服官服与国际服之间的差异文件。

⇄

复用本地资源

优先复用本地已校验文件，保存反向切换所需差异，并分别管理各资源服的热更新缓存。

↶

备份与恢复

替换前建立备份，结合文件校验与事务记录，在操作意外中断后提供恢复依据。

02

使用步骤

首次使用需要联网准备差异资源。
后续切换可复用已校验的文件与缓存。

01

下载并解压

从 GitHub Releases 下载最新版，解压后运行 ZZZSwitch.exe。

02

选择游戏目录

自动检测，或手动选择包含 ZenlessZoneZero.exe 的安装目录。

03

检查并切换

选择目标服务器，在完整模式中查看检查结果与切换摘要，再开始操作。

04

启动目标服

等待切换完成，再启动游戏。首次进入目标服可能需要下载游戏内资源。

!
切换前，请完全关闭游戏和 HoYoPlay。

切换完成后再启动。不要在非对应服务器状态下使用启动器“修复”；首次进入其他服务器仍可能需要下载游戏内热更新资源。

阅读完整使用说明 ↗
需要重新下载整个游戏吗？

不需要额外下载一套完整客户端。ZZZSwitch 会比较目标服 Manifest 与现有文件，优先复用已校验资源，仅下载缺少的目标差异；游戏内热更新资源另行处理。

B服需要单独下载组件包吗？

当前支持游戏版本的 B服渠道组件已包含在正式程序中，ZZZSwitch 会自动校验并准备这些组件。

切服后为什么还会下载游戏内资源？

启动文件差异与游戏内热更新资源是两套内容。ZZZSwitch 分别保存各资源服的 Blocks 缓存，但首次进入目标服仍可能需要完成资源下载。

操作中断后，可以恢复吗？

实际替换前会创建事务备份。操作意外中断后，重新启动 ZZZSwitch，程序会依据事务记录尝试恢复；也可在备份历史中查看可用备份及恢复条件。

三个服务器的账号和进度会互通吗？

不会。ZZZSwitch 切换的是本地客户端文件与资源，不提供跨服务器账号、角色或游戏进度转移。请使用目标服务器对应的账号登录。
