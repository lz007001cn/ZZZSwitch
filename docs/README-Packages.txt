ZZZSwitch Packages 3.1.0
========================

本压缩包包含绝区零 3.1.0 国际服、国服和 B服差异文件，目录分别为
global、cn_official 和 bilibili。三服差异文件在同一个 ZIP 中分发，
不需要再安装单独的 B服扩展压缩包。
不包含 Persistent\Blocks、seed、任何 .blk 热更新资源、用户账号数据、备份、
日志或本机缓存清单。

安装方法
--------

将压缩包中的 .zzzswitch 文件夹解压到游戏文件夹的上一级目录。

例如游戏目录为：
E:\HoYoPlay\games\ZenlessZoneZero Game

解压后应得到：
E:\HoYoPlay\games\.zzzswitch\packages\3.1.0

不要把 .zzzswitch 解压进 ZenlessZoneZero Game 文件夹内部。

该资源包仅适用于游戏版本 3.1.0。游戏更新后，应等待对应版本的新差异包。
