# 测试说明

测试项目不使用 NuGet 测试框架，避免引入第三方依赖。它是一个返回标准退出码的 .NET 8 控制台程序。

运行：

```powershell
dotnet run --project tests\ZZZSwitch.Core.Tests\ZZZSwitch.Core.Tests.csproj -c Release
```

所有 fixture 位于 `%TEMP%\ZZZSwitch.Tests\<guid>`，测试结束后递归删除自己的 GUID 子目录。测试从不使用配置中的真实 `E:` 游戏路径。

当前核心测试覆盖三服识别与 B服/国服资源归一、六个切换方向所依赖的计划、路径安全、游戏目录与版本、差异包逐文件长度和 SHA-256、在线差异生成与本地复用、实际变化文件筛选、事务备份与回滚、缓存快照、Blocks 交换与中断恢复、多安装隔离、存储迁移、内置 B服组件、配置容错和并发互斥。测试以用户可观察结果为主，不固定普通配置或 Manifest 文本的 SHA-256，也不要求 JSON 属性顺序或作者手填的文件数量保持不变。

WPF UI 冒烟测试还验证：正式版三服入口；主页无“导入差异包”和“初始化当前服缓存”按钮，并提供“差异包管理”；客户端差异包管理窗口打开后默认选中当前版本包，显示双向包和 Sophon Manifest 占用，提供刷新、Manifest 更新、Manifest 浏览、差异包清单预览、SHA-256 校验和差异包更新操作；Manifest 浏览器可切换方向、六种资源范围和路径搜索；ToolTip 与管理、浏览、预览、下载窗口完整绑定深浅主题资源，不再出现深色主题白色空白条；客户端差异包下载窗口的范围、进度、失败重试和旧差异包禁用说明；右上角旧主题按钮已移除；浅色标题栏与品牌标识无黑块；主题三态和中文/English 动态资源；`MainWindowViewModel` 绑定和忙碌状态传播；三服 Command 路由、忙碌禁用、重复执行保护及同步/异步异常转交；复用服务器卡片属性；扫描展示格式化器和独立摘要控件；主窗口默认宽度与最窄窗口在扫描前后宽高不变；主窗口 125%、150%、200% 布局缩放压力；设置窗口最窄尺寸及 125%/200% 缩放布局；缓存与备份位置窗口；“恢复上次状态”位于备份历史而非主界面；同服切换在规划前短路、忙碌状态在扫描前短路、无效扫描报告阻止缓存管理、备份目录打开动作使用当前配置路径。

启动 UI 编排测试使用纯委托和临时路径验证：恢复结果与状态警告完整传递；备份轮换使用 `state.json` 中精确的最后备份保护路径；轮换异常不会中断启动；零个/单个游戏目录候选无需打开交互选择窗口。

`ZZZSwitch.Ui.Smoke` 在 STA 线程中实例化 WPF 资源和窗口但不显示窗口、不触发 `App.OnStartup`、不读取游戏目录；它检查正式版三服按钮、版本号以及缓存管理操作状态。

故障场景通过 `IFileOperations` 包装器精确注入一次复制或删除失败，随后让正常文件操作完成回滚，能够验证真实恢复结果而不是只验证返回值。

切换反馈回归还覆盖：修改游戏文件前失败、完整回滚、回滚自身失败三种结果；校验、暂存、备份和回滚期间显示活动进度，逐文件执行阶段显示数量；主窗口与精简窗口共享状态；中英文失败提示保留预检路径和恢复建议，精简窗口可通过悬浮提示查看完整错误。

失败提示及精简模式弹窗策略通过 `ServerSwitchWorkflow.RunAsync` 验证，使用临时两文件差异包和真实规划器、执行器，只替换交互边界、进程检测和故障文件操作。三种故障分别在两种语言、主窗口/精简模式下执行，同时核对文件内容、未提交的目标服状态、事务保留与备份路径；不再反射调用私有失败格式化或弹窗策略方法。少量窗口状态适配和布局检查仍通过反射驱动，以免为测试扩大生产接口。

## 每次修改后的可运行测试版

每次完成实现修改后，除构建和自动测试外，还必须生成一个可直接双击运行的 Windows x64 自包含测试版：

```powershell
.\build-runnable-test.ps1
```

脚本会依次执行解决方案 Release 构建、核心测试、ManifestTool 测试、UI smoke 和独立 Manifest 演示工具测试。全部通过后才发布测试版；验证失败时保留上一次成功版本。

固定输出：

```text
_verification\runnable-test\current\ZZZSwitch.exe
```

同目录还会生成：

```text
BUILD-INFO.json
SHA256SUMS-TEST.txt
README.md
config\
```

该目录属于忽略的可再生成验证输出，不覆盖 `publish`、`dist` 或任何历史发布物，也不会自动启动程序或访问真实游戏目录。
