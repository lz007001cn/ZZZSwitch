# ZZZSwitch 1.2.2

## 主要变化

- 修正 v1.2.1 的备份保留口径：每份游戏安装按来源服设置备份槽，国服、国际服、B服各保留一份最新的成功可恢复备份，因此最多三份。
- 同一来源服再次切出时，新备份在切换完全提交后替代该服旧备份；即使切换目标不同，也不会增加槽位。
- B服虽然与国服复用 Blocks 和 version/revision 资源，但普通客户端叠加文件状态不同，因此仍保留独立来源服备份槽。
- 新版启动时按游戏安装和来源服分别轮换旧版遗留的有效备份。
- 已完整回滚的失败备份、已手动恢复的备份，以及启动时已完整恢复的中断备份不占来源服槽位。
- 回滚或启动恢复未完成、记录损坏或缺失的目录仍保留供人工排查，避免误删唯一恢复依据。
- 主页“恢复上次状态”只使用 `state.json` 精确指向的最后一次切换备份，并校验操作 ID、当前目标服、游戏版本和游戏目录。

## 兼容与保留

- 原 v1.2.1、v1.2.0、v1.1.3 和 v1.2.0-preview.3 发布目录、压缩包及校验文件全部保留。
- 游戏差异包仍为 3.1.0，本次只需更新 ZZZSwitch 本体。
- 安全异常记录可能使磁盘上的目录暂时超过三份；它们不会被自动当作普通旧备份删除。

## 验证

- Release 与 B服条件构建：0 警告、0 错误。
- 核心自动测试：79/79。
- UI 结构冒烟测试通过。
- 自动测试只使用系统临时目录；未修改真实游戏目录或真实备份。
