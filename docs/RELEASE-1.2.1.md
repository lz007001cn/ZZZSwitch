# ZZZSwitch 1.2.1

## 主要变化

- 每份游戏安装最多保留最近三份成功且可恢复的事务备份。
- 新版启动时按游戏安装路径分别轮换旧版遗留的有效备份，不再只维护当前安装。
- 已完整回滚的失败备份、已手动恢复的备份，以及启动时已完整恢复的中断备份不会占用三份配额。
- 回滚或启动恢复未完成、记录损坏或缺失的目录仍保留供人工排查，避免误删唯一恢复依据。
- 系统时间回拨时优先保护刚提交或状态记录的备份，轮换维护失败不会反向影响已完成的切换。

## 兼容与保留

- 原 v1.2.0、v1.1.3 和 v1.2.0-preview.3 发布目录、压缩包及校验文件全部保留。
- 游戏差异包仍为 3.1.0，本次只需更新 ZZZSwitch 本体。
- 旧版应用数据目录中的 `Backups` 不属于当前应用数据根目录，不会被程序自动删除。

- UI 结构冒烟测试通过。
