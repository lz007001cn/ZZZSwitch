# ZZZSwitch 1.2.6

## 新增

- 新增紧凑设置页，集中管理中文/English、跟随 Windows/深色/浅色主题、缓存与备份位置、启动行为、窗口记忆以及 7/30 天日志保留。
- 浅色模式覆盖主窗口标题品牌区和子窗口，右上角旧主题按钮已移除。
- “差异包目录”改为“导入差异包”：可直接选择三服统一 ZIP，自动解压到当前游戏版本的标准目录。

## 修复与安全性

- 修复旧版本缓存含只读/System 文件时无法清理的问题。
- 旧缓存目录已手动删除但清单仍残留时，现在也会显示并清理。
- 差异包导入先在临时目录完成三服结构、版本及逐文件校验，再原子替换现有同版本目录；失败保留原内容。
- 增加游戏升级隔离测试，确认新版本未初始化时不会复用旧版本 Blocks 缓存。
- 增加热更新保存测试，确认初始化后新增的 Blocks 文件会在切走当前服时自动纳入缓存。
- 文件选择窗口标题统一为“选择文件”。
- 日志按选择的 7/30 天周期自动清理，并保留“打开目录”入口。
- 设置窗口底部操作改为“保存”；浅色主题下三服图标统一使用圆角遮罩，消除透明边缘的黑色残余。

游戏差异包版本仍为 3.1.0；本次无需重新制作差异包。
