# ZZZSwitch 1.2.0

## 主要变化

- 将 B服识别、切换、登录窗提示和六方向配置并入普通 Release 构建。
- B服作为国服资源叠加层，与国服共用 Blocks 和 version/revision 快照。
- 新增缓存管理界面：查看占用、清理旧游戏版本、迁移到自定义目录、恢复默认位置。
- 同卷缓存继续快速移动；跨磁盘缓存使用可恢复的暂存复制与清单校验。
- 修复热缓存事务在首次移动前中断时可能误删活动 Blocks 的风险。
- 每份游戏安装只轮换保留最近一份可恢复切换备份；备份创建失败时清理不完整目录。

## 兼容与保留

- 原 v1.1.3 正式发布目录/压缩包及校验文件保留。
- 原 v1.2.0-preview.3 B服实验发布目录/压缩包及校验文件保留。
- 游戏差异包版本仍为 3.1.0；B服叠加包需要与基础 3.1.0 差异包一起安装。

## 验证

- Release 构建：0 警告、0 错误。
- 核心自动测试：77/77。
- 所有自动测试只使用系统临时目录；未读取或修改真实游戏目录。
