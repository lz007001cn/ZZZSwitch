# ZZZSwitch

[English](README.md) | 简体中文

🌐 [项目主页](https://lz007001cn.github.io/ZZZSwitch/) · [下载最新版](https://github.com/lz007001cn/ZZZSwitch/releases/latest)

ZZZSwitch 是一款适用于 Windows 的《绝区零》服务器切换工具，支持**国际服、国服官服和 B服**客户端。

国际服与国服官服之间的切换使用当前游戏版本对应的官方 Sophon Manifest。程序会优先复用当前客户端中符合目标 Manifest 的文件，仅下载缺少的目标文件，并在覆盖前保存来源服差异文件，因此反向切换可以继续使用本地数据，不需要重新下载原客户端。B服仍作为国服资源上的渠道组件叠加层；1.3.4 起，当前支持版本的 B服渠道组件已包含在软件本体中。

## 主要功能

- 自动检测《绝区零》安装目录，也可以手动选择。
- 支持中文、English、深浅主题和首次启动新手引导。
- 完整版窗口集中显示客户端状态，并提供差异包、缓存、备份和设置管理。
- 精简版窗口仅保留三服切换入口，显示当前服务器高亮，并在左下角展示切换进度与结果。
- 默认后台运行到系统托盘；左键单击托盘图标打开已配置的窗口，右键菜单可打开完整版、精简版或退出。
- 可选择关闭窗口时隐藏到托盘，或直接退出程序。
- 按当前游戏版本获取和浏览国际服/国服 Sophon Manifest。
- 自动复用已验证的本地文件、完整差异包和断点分块。
- 切换前自动保存各服务器热更新缓存，无需手动初始化。
- 支持自定义缓存与备份位置、旧版本缓存清理、启动行为和日志保留设置。
- 在设置页静默检查 GitHub Releases，显示当前版本、最新版本和更新说明，并在安装前使用 GitHub 提供的 SHA-256 校验更新包。
- 使用 MD5/SHA-256 校验、事务备份、回滚日志、进程检查和安全路径校验保护切换过程。

## 运行要求

- Windows x64。
- 已安装《绝区零》PC 客户端。
- 国际服 ↔ 国服官服切换需要联网获取 Manifest，以及下载本地无法复用的目标文件。
- 国际服与 B服直接切换需要对应版本的国际服/国服基础差异，程序可以自动下载或复用本地数据；B服渠道组件本身无需另行下载。

## 使用说明

1. 从 [最新 Release](https://github.com/lz007001cn/ZZZSwitch/releases/latest) 下载 `ZZZSwitch-win-x64-v1.4.0.zip`，解压到任意目录后运行 `ZZZSwitch.exe`。

2. 首次启动时完成新手引导：
   - 选择中文或 English 以及界面主题；
   - 自动检测或手动选择《绝区零》游戏目录；
   - 选择默认启动窗口和关闭行为。

3. 开始切换前，完全退出《绝区零》和 HoYoPlay。

4. 选择目标服务器：
   - **国际服 ↔ 国服官服：**程序会检查正反两个方向，按需读取对应 Manifest，保存可复用的来源文件，并且只下载目标方向缺少的文件。
   - **B服：**首次识别到受支持的游戏版本时，程序会把内置 B服渠道组件自动校验并存入 `.zzzswitch\packages\<游戏版本>\bilibili`。国服与 B服之间只需应用这个小型叠加组件；国际服与 B服之间会把它与在线国际服/国服基础差异组合到同一套可恢复事务中。B服与国服共用 Blocks 资源，同时保留独立渠道身份。

5. 完整版窗口会显示切换摘要并要求确认。精简版点击服务器后直接开始切换，不再弹出确认或完成窗口，进度和结果显示在左下角。

6. 程序会先备份受影响文件、保存来源服热更新缓存，再执行替换。下载取消或网络失败时保留已经验证的完整文件和分块，重试不会从零开始。

7. 切换完成后启动游戏，并完成目标服务器可能要求的资源下载。首次进入其他服务器仍可能需要在游戏内下载约 **3–10 GB** 资源。

8. 默认关闭窗口后程序隐藏到系统托盘。左键单击一次托盘图标即可重新打开已配置的窗口，也可以使用右键菜单；如需直接退出，可在设置中启用“关闭时退出程序”。

## 软件更新

从 v1.4.0 开始，打开“设置”时程序会静默检查最新的稳定版 GitHub Release，并显示当前版本、最新版本、发布日期和更新说明。检查过程不会打断正常使用，也不会单独弹窗。

点击“安装更新”后，程序下载官方 Windows x64 ZIP，校验声明大小以及 GitHub 提供的 SHA-256；全部通过后才会交给独立 Updater。ZZZSwitch 随后退出、替换程序文件、自动重启，并记录安装结果。下载不完整或 SHA-256 不一致的安装包不会被安装。

## 差异包、Manifest 与缓存

主页的“差异包管理”可以查看已保存版本、更新或浏览 Manifest、预览和校验完整差异包、继续更新差异包，以及删除选中的本地数据。

`%LOCALAPPDATA%\ZZZSwitch` 保存设置、状态、锁、日志、事务控制文件和临时软件更新任务。游戏切换使用的受管数据在当前游戏安装下采用明确目录：事务备份默认位于 `.zzzswitch\app-data\backup-records`，自动下载的国际服/国服差异位于 `.zzzswitch\app-data\downloads`，元数据分别位于 `snapshots`、`sophon-manifests` 和 `blocks-manifests`，大型分服 Blocks 缓存位于 `.zzzswitch\blocks-cache`。`.zzzswitch\packages` 单独保存只读离线输入，默认包含内置 B服叠加组件；只有用户主动导入统一离线包时才会包含国际服/国服文件。旧 `data` / `cache` 布局和 AppData 载荷会在使用前迁移；短期使用过的 `backup-content` 对象布局仍可读取旧备份，但不再创建。语言、主题、缓存位置、备份位置、启动模式、关闭行为和日志保留时间都可以在“设置”中调整。

差异包和缓存按游戏安装目录与游戏版本隔离。游戏更新后，程序会建立新版本的 Manifest、差异包和缓存记录，不会套用旧版本文件；旧版本 Blocks、自有 Manifest 和元数据快照可以一起清理，包括只读残留。旧版固定 `global` / `cn_official` 差异包目录仍可兼容读取，但自动切换不再依赖它们，也不会在没有明确清理操作时删除。

## 安全说明

> [!IMPORTANT]
> 游戏或 HoYoPlay 运行时不要执行切换。在 ZZZSwitch 明确提示操作完成前，请保持游戏和启动器关闭。

- 游戏版本、必需文件大小、MD5 或 SHA-256 校验不通过时，程序不会应用差异包。
- 国际服/国服在线切换不会回退使用 `.zzzswitch\packages` 中的旧替换包。
- `Persistent\Blocks` 作为按服热更新缓存管理；`Persistent\Video` 不会被移动、复制、校验或删除。
- 普通文件替换、Blocks 交换、状态写入和外部备份处于同一套可恢复事务中。
- 操作意外中断后，程序会在下次启动时依据事务日志和回滚备份尝试恢复。
